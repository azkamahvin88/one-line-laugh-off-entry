Exactly one funny line for make.fun's "One-Line Laugh-Off" bounty ($2, winner-take-all) — a single joke that lands on a cold read, with no setup notes and no explanation.

> I asked the barista for something strong. She handed me her resignation letter.

The program (`main.ts`, Node 22+) writes that single line — 79 characters — to `/output/entry.txt`. No network, no model calls, fully deterministic.

## Run it

```sh
node main.ts
```
